DESTINY CLOUD — LOGO ASSET PACKAGE
Selected direction: concept 08, the restrained orange horizon arc and baseline.

QUICK START
- Web / print / design software: use SVG masters.
- Standard raster use: PNG.
- Email, office documents, and quick previews: JPG.
- PDF contains a one-page overview.
- Favicon folder contains SVG, ICO, and common PNG sizes.

VARIANTS
For each lockup (horizontal, stacked, wordmark, symbol):
- *_dark: full-colour logo on Ink background
- *_light: full-colour logo on white background
- *_mono_ivory: one-colour Ivory on Ink
- *_mono_ink: one-colour Ink on white
- *_transparent: transparent-background SVG/PNG/JPG preview (JPG is flattened on Ink)

APP / FAVICON
- app_icon_orange: rounded-square Ink tile with orange arc
- app_icon_mono_ivory: monochrome rounded-square tile
- favicon.svg, favicon.ico, favicon-16.png through favicon-512.png

BRAND COLOURS

TYPE
Wordmark uses an Inter / Arial sans-serif fallback stack in SVG. For consistent production, use Inter or a similar modern grotesk. If sending to a print vendor, convert text to outlines in a vector editor after confirming the exact typeface.

NOTES
The SVG files are scalable vector masters. PNGs preserve transparency where applicable; JPGs are always flattened because JPEG does not support transparency. This is a logo asset starter package, not trademark clearance or a full brand standards manual.
